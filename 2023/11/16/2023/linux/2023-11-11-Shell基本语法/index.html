简介

Shell是一个用C语言编写的程序，是用户使用Linux的桥梁。Shell既是命令语言，也是程序设计语言。

Shell指的是一种应用程序，可以通过此程序访问操作系统内核服务。

Shell脚本则是一种为Shell编写的脚本程序。Shell和Shell Script（Shell脚本是两个不同的概念）。本文主要记录Shell脚本编程。

一个图看懂Shell在Linux系统中扮演的角色：

Shell环境

Linux的Shell种类很多，常见的有：

  • Bourne Shell（/usr/bin/sh或/bin/sh）
  • Bourne Again Shell（/bin/bash）
  • C Shell（/usr/bin/csh）
  • K Shell（/usr/bin/ksh）
  • Shell for Root（/sbin/sh）
  • …….

变量

定义变量，等号两边不能有空格:

  • 命名只能使用英文字母，数字和下划线，首个字符不能以数字开头。
  • 中间不能有空格，可以使用下划线 _。
  • 不能使用标点符号。
  • 不能使用bash里的关键字（可用help命令查看保留关键字）。

传递的参数

脚本内获取参数的格式$n，其中$0为执行的文件名，$1为执行的第一个参数，以此类推。

特殊字符

$# 传递到脚本的参数个数
$* 以一个单字符串显示所有向脚本传递的参数
$$ 脚本运行的当前进程ID号
$! 后台运行的最后一个进程ID号
$@ *与$相同，只不过不是以但字符串的方式返回，而是分别返回
$- 显示Shell使用的当前选项，与set命令相同
$？ 显示最后的退出状态。0表示没有错误，其它任何值表示有错

运算符

Shell支持多种运算符：

  • 算数运算符
  • 关系运算符
  • 布尔运算符
  • 字符串运算符
  • 文件测试运算符

算数运算符

a=10,b=20

运算符 说明 例子
+ 加 expr $a + $b结果为30
- 减 expr $a - $b结果为-10
* 乘 expr $a \* $b结果为200
/ 除 expr $b / $a结果为2
% 区域 expr $a % $b结果为10
= 赋值 a = $b 把20赋值给a
== 相等 [ $a == $b ] 结果为 false
!= 不相等 [ $a != $b ] 结果为true

expr 是表达式计算，注意由于 * 是Linux的关键字，所以需要使用转义字符，或者使用 $(())进行计算，运算符旁边也不需要空格。

注意表达式两边要有空格

脚本执行结果

关系运算符

a=10,b=20

运算符 说明 例子
-eq 两个值是否相等 [ $a -eq $b ] 或 test [$a] -eq [$b] 返回 false
-ne 两个值是否不相等 [ $a -ne $b ] true
-gt 左边值是否大于右边值 [ $a -gt $b ] false
-lt 左边值是否小于右边值 [ $a -lt $b ] false
-ge 左边值是否大于等于右边值 [ $a -ge $b ] false
-le 左边值是否小于等于右边值 [ $a -le $b ] true

布尔运算符

a=10,b=20

运算符 说明 举例
! 非运算 [ ! false ] true。
-o 或运算，有一个表达式为 true 则返回 true。 [ $a -lt 15 -o $b -gt 50 ] true。
-a 与运算，两个表达式都为 true 才返回 true。 [ $a -lt 15 -a $b -gt 50] false。

逻辑运算符

a=10,b=20

运算符 说明 举例
&& 逻辑的 AND [[ $a -lt 50 && $b -gt 50 ]] false
|| 逻辑的 OR [[ $a -lt 50 || $b -gt 50 ]] true

字符串运算符

字符串a=”abc”，b=”qwe”

运算符 说明 举例
= 两个字符串是否相等 [ $a = $b ] false。
!= 两个字符串是否不相等 [ $a != $b ] true。
-n 字符串长度是否不为 0 [ -n “$b” ] true。
-z 字符串长度是否为0 [ -z $b ] false。
$ 字符串是否不为空 [ $b ] true。

文件测试运算符

操作符 说明
-b file 检测文件是否是块设备文件
-c file 检测文件是否是字符设备文件
-d file 检测文件是否是目录
-f file 检测文件是否是普通文件（既不是目录，也不是设备文件）
-g file 检测文件是否设置了 SGID 位
-k file 检测文件是否设置了粘着位(Sticky Bit)
-p file 检测文件是否是有名管道
-u file 检测文件是否设置了 SUID 位
-r file 检测文件是否可读
-w file 检测文件是否可写
-x file 检测文件是否可执行
-s file 检测文件是否为空（文件大小是否大于0）
-e file 检测文件（包括目录）是否存在

输入输出重定向

Linux可以将终端或者文件方式输入的内容，转到另一个目标中去。

Linux有关重定向有三种与之关联的文件描述符：

  • 0：指标准输入(STDIN)
  • 1：指标准输出(STDOUT)
  • 2.：指标准错误输出(STDERR)
