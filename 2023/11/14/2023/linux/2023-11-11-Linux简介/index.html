简介

Linux 内核最初只是由芬兰人林纳斯·托瓦兹（Linus Torvalds）在赫尔辛基大学上学时出于个人爱好而编写的。

Linux 是一套免费使用和自由传播的类 Unix 操作系统，是一个基于 POSIX 和 UNIX 的多用户、多任务、支持多线程和多 CPU 的操作系统。

Linux 能运行主要的 UNIX 工具软件、应用程序和网络协议。它支持 32 位和 64 位硬件。Linux 继承了 Unix 以网络为核心的设计思想，是一个性能稳定的多用户网络操作系统。

发行版

目前市场比较有名的发行版：Ubuntu、RedHat、CentOS、Debian、Fedora、SuSE、OpenSUSE、Arch Linux、SolusOS 等。

Linux vs Windows

Windows界面统一，驱动程序丰富，版本更新频繁。使用比较简单，很适合普通人群使用。比较多的用于办公室办公、学习等。

Linux的界面风格随发行版，可能也互不兼容。GNU/Linux 的终端机是从 UNIX 传承下来，基本命令和操作方法也几乎一致。比较多的用于服务器。

启动过程

init程序的类型

  • SysV: init, CentOS 5之前, 配置文件： /etc/inittab。

  • Upstart: init,CentOS 6, 配置文件： /etc/inittab, /etc/init/*.conf。

  • Systemd： systemd, CentOS 7,配置文件： /usr/lib/systemd/system、 /etc/systemd/system。

内核引导

计算机打开电源后，会对BIOS（基本输入输出系统）进行开机自检，按照BIOS设置的启动设备（一般是硬盘）进行启动。操作系统接管硬件之后，会读入 /boot 目录下的内核文件。

运行init

init程序会去读取配置文件 /etc/inittab。用来引导启动其它进程。

运行级别

Linux系统有7个运行级别，根据不同的场景，从而分配不同的开机启动程序。

  • 运行级别0：系统的停机状态，若设置为此运行级别，则系统将不能启动。
  • 运行级别1：单用户的工作状态，只有root权限，适用于系统维护，并且不能远程登录。
  • 运行级别2：多用户的状态。没有NFS。
  • 运行级别3：完全的多用户状态，有NFS。登录后进入控制台模式。
  • 运行级别4：保留。
  • 运行级别5：登录后进入GUI模式，也就是图形界面。
  • 运行级别6：系统重启模式，若设置此级别，则系统陷入重启循环。

系统初始化

Init会调用执行 /etc/rc.d/rc.sysinit，而rc.sysinit是一个bash shell脚本，主要完成一些系统初始化的工作。激活交换分区、检查磁盘、加载硬件模块以及其它需要优先执行的任务。/etc/rc.d/rc5.d/目录中的启动脚本其实是一些连接文件，真正的rc启动脚本在/etc/rc.d/init.d/下。

我们可以在/etc/rc.d/init.d下添加我们自定义的启动脚本。

建立终端

rc执行之后，返回init。这个时候基本环境已经设置好了，各种的守护线程也已经启动。init会打开6个终端，供用户登录使用。

tty1、tty2、tty3、tty4、tty5、tty6。

使用快捷键Ctrl + Alt + F1 ~ F6 在命令行界面之间切换。

在命令行界面使用快捷键Ctrl + Alt + F7切回图形化界面。

如果使用的VM虚拟机，命令行之间切换使用Alt + Space + F1F6。在图形化界面使用Alt + Shift + Ctrl + F1F6 切换到命令行界面。

因为不是新安装的虚拟机，可能存在后续添加的目录，这里只记录重要的目录。

  • /bin：
    存放经常使用的程序或命令

  • /boot：
    存放系统的内核文件，包含连接文件、镜像文件。

  • /dev ：
    Device(设备) 的缩写, 存放Linux的外部设备。

  • /etc：
    存放所有系统需要的配置文件以及子目录列表，不能轻易更改，可能导致系统无法正常启动。

  • /home：
    用户的主目录，以用户的账号命名。

  • /lib：
    Library(库) 的缩写，存放基本的代码库（c++库），与Windows里面的DLL文件相似。

  • /media：
    linux 系统会自动识别一些设备，例如U盘、光驱等等，当识别后，Linux 会把识别的设备挂载到这个目录下。

  • /mnt：
    系统提供该目录是为了让用户临时挂载别的文件系统的，我们可以将自己的U盘等设备挂载到/mnt目录，这样就可以查看数据了。

  • /opt：
    Optional(可选) 的缩写，默认为空，额外安装的软件可以放在里面。

  • /proc：
    Processes(进程) 的缩写，/proc 是一种伪文件系统，也就是虚拟的目录，是系统内存的映射，我们可以通过访问此目录，获取系统信息。可以通过此目录，来获取进程的Id。此目录的内容在内存上，可以直接修改某些文件。

    下面的命令可以屏蔽主机的ping命令，使别人无法ping你的机器（icmp_echo_ignore_all的值默认为0）：

  • /root：
    系统管理员用户的主目录。

  • /sbin：
    只能系统管理员使用的命令或者程序。

  • /srv：
    该目录存放一些服务启动之后需要提取的数据。

  • /sys：

    这是 Linux2.6 内核的一个很大的变化。该目录下安装了 2.6 内核中新出现的一个文件系统 sysfs 。

    sysfs 文件系统集成了下面3种文件系统的信息：针对进程信息的 proc 文件系统、针对设备的 devfs 文件系统以及针对伪终端的 devpts 文件系统。

    该文件系统是内核设备树的一个直观反映。

    当一个内核对象被创建的时候，对应的文件和目录也在内核对象子系统中被创建。

  • /tmp：
    Temporary(临时) 的缩写，存放临时文件。

  • /usr：
    unix shared resources(共享资源) 的缩写，用户的很多应用程序和文件都放在这个目录下，类似于 windows 下的 program files 目录。

  • /usr/bin：
    系统用户使用的应用程序。

  • /usr/sbin：
    超级用户使用的比较高级的管理程序和系统守护程序。

  • /usr/src：
    内核源代码默认的放置目录。

  • /var：
    Variable(变量) 的缩写，存放经常修改的数据，比如日志文件就在此目录下。

  • /run：
    临时文件，用来存储系统启动以来的信息。当系统重启之后，这个目录下的文件应该被删除或者清除。

磁盘管理

Linux磁盘管理的常用命令有 df、du、fdisk。

  • df（英文全称：disk free）：列出文件系统的整体磁盘使用量
  • du（英文全称：disk used）：检查磁盘空间使用量
  • fdisk：用于磁盘分区

1.df命令

检查磁盘空间的占用情况

  • -a ：列出所有的文件系统，包括系统特有的 /proc 等文件系统；
  • -k ：以 KBytes 的容量显示各文件系统；
  • -m ：以 MBytes 的容量显示各文件系统；
  • -h ：以人们较易阅读的 GBytes, MBytes, KBytes 等格式自行显示；
  • -H ：以 M=1000K 取代 M=1024K 的进位方式；
  • -T ：显示文件系统类型, 连同该 partition 的 filesystem 名称 (例如 ext3) 也列出；
  • -i ：不用硬盘容量，而以 inode 的数量来显示

使用易读的方式显示磁盘容量

2.du命令

与df命令不同的是，du命令是对文件和目录磁盘使用空间的查看

  • -a ：列出所有的文件与目录容量，因为默认仅统计目录底下的文件量而已。
  • -h ：以人们较易读的容量格式 (G/M) 显示；
  • -s ：仅显示指定目录或文件的总大小，而不显示其子目录的大小。
  • -S ：包括子目录下的总计，与 -s 有点差别。
  • -k ：以 KBytes 列出容量显示；
  • -m ：以 MBytes 列出容量显示；
