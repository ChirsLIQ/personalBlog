从零开始搭建一个电商项目-基础环境搭建（二）

2023-01-11
瞎胡闹
Word count: 1.2k   |   Reading time≈ 5 min

  1. 搭建微服务项目

    Spring Boot 版本 2.3.7
    Spring Cloud 版本 Hoxton.SR9
    Spring Alibaba 版本 2.1.1
    Java 版本 1.8
    后端项目地址：https://gitee.com/chris_777/easymall dev分支
    前端项目地址：https://gitee.com/chris_777/easymall-vue

  2. 数据库

    easy_mall_admin 后台管理数据库
    easy_mall_oms 订单数据库
    easy_mall_pms 商品数据库
    easy_mall_sms 优惠数据库
    easy_mall_ums 会员数据库
    easy_mall_wms 仓储数据库
    地址：https://gitee.com/chris_777/easymall/tree/develop/sql

  3. 安装中间件

    注意：需要安装docker，会有另一篇文章讲，docker建议 20 版本以下，后期兼容安装K8S
    Redis：主要用于缓存、分布式锁、分布式Session

​ Nginx：用于转发用户请求到后台服务，静动态资源分离（项目中目前没做）

​ Minio：文件上传工具

​ Rabbitmq：用于分布式事务、延时队列

​ Nacos：注册中心、配置中心（目前没用）

​ mysql：宿主机原先已经安装，此项目没有进行安装操作，可以网上搜索安装教程。推荐使用 docker安装，比较简单。

​ Elasticsearch：商品信息检索
​ Kibana：图形化展示ES中的索引等信息

  1. 人人开源

    网址： https://gitee.com/renrenio
    renren-fast ：后台管理系统
    renren-fast-vue：前端项目
    根据文档中的操作步骤，换成自己的数据库。
