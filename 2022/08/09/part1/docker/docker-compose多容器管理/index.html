  1. Compose 是什么

    Compose 是用于定义和运行多容器 Docker 应用程序的工具。可以使用yml配置文件来配置并管理所有的服务。然后使用一个命令，就可以创建以及启动所有的服务。

  4. 小结

    本文主要介绍如何使用docker-compose来管理并运行多个容器，例子比较简单。主要想给大家演示，如何根据yml配置去管理多个容器。一般在公司进行项目开发时，会涉及到多个开发环境，比如开发、测试、发布等。那么我们可以根据以上环境去创建三个容器，在需要发布相应环境的时候，我们只需要将打包好的jar包制作成镜像，然后在yml文件中启动相应的服务即可（需在Idea中集成）。

    可能出现的困惑：

    为什么例子中要使用本地的dockerfile文件进行构建容器？

    答：我这个例子是这么用的。可以直接使用已经存在的镜像启动容器。还有就是使用dockerfile文件，将dockerfile文件以及yml配置文件放到服务区上，在服务器上使用docker-compose的命令，仍然能达到最终目的，只不过本例子中Idea帮助我们执行了。还记得刚开始需要下载docker-compose的软件吗，就是需要在安装Idea编辑软件的机器上去执行docker-compose命令。
