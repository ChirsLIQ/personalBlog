  1. 什么是Docker

    官方解释：

    ​ Docker 是一个开源的应用容器引擎，让开发者可以打包他们的应用以及依赖包到一个可移植的容器中,然后发布到任何流行的Linux或Windows操作系统的机器上,也可以实现虚拟化,容器是完全使用沙箱机制,相互之间不会有任何接口

    个人理解：

    ​ 如果一个服务器需要部署多个应用程序，那么当一个应用程序的执行出现问题，比如内存溢出，死循环等情况时，会影响其它影响程序的运行。那么可以使用Docker来分别管理应用程序，并且可以设置每个应用程序的占用资源大小，岂不美哉！

  2. 下载Docker

    我这里使用的Centos，依次执行以下命令：

    添加阿里云镜像，这样下载就快了

    下载Docker

    查看docker的版本，如果有显示则表示安装成功

    启动docker

    配置一下阿里云镜像源吧，这样下载镜像的时候就快很多了，直接找到文件 /etc/docker/daemon.json,没有就创建，添加以下内容：

    {

    “registry-mirrors”: [“https://ukdgcz5v.mirror.aliyuncs.com"]

    }

    拉一下Hello-word镜像，执行感受一下吧

    顺便修改一下Docker对外连接的端口吧，首先打开 /usr/lib/systemd/system/docker.service文件，找到 ExecStart关键字，在后面添加以下内容 -H tcp://0.0.0.0:2375，2375就是对外连接的端口号，用于Idea的docker客户端连接，可以改成自己要设置的端口。
