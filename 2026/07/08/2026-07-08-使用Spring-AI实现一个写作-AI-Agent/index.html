使用Spring AI实现一个简单的写作AI Agent

1.背景

AI时代的到来，现在直接丢需求给AI，就能在极短时间内完成我们几天需要完成的工作。虽然需要修修补补，但整体的时效比”远古编程“高太多。 像现在熟悉的Codex，就是远超传统文本对话模型的AI Agent。所以通过一个简单的写作AI Agent了解学习一下Agent是如何工作的。

本文基于Spring AI框架，集合MCP（模型上下文协议），构建一个写作智能体。可以完美浅入到你自己的Spring Boot项目中。

2.系统架构设计

2.1设计模式：链式工作流（Chain Workflow）

写作具有天生的顺序性，所以采取链式工作流。将一整个任务拆分为多个任务，依次分步完成：

  1. 主题生成：Agent根据用户输入的提示词，生成一个具体的写作题目。
  2. 大纲规划：生成二级、三级标题
  3. 全文撰写：按照大纲写出全文
  4. 润色和终稿：优化预期、纠正语法。

2.2分层架构

采用三层架构+工具层：

  • Agent Controller：接收用户的请求
  • Agent Service：：编排工作流，维护会话记忆，决定何时调用工具。
  • ChatClient：Spring AI提供的调用统一LLM的一个客户端。
  • 本地工具集：Java注解 @Tool，生成一个可以本地调用的工具方法。比如执行某个灯效。
  • MCP 客户端：可以将工具处理逻辑部署到另一台机器上，供客户端调用。

2.3核心数据流

  1. 用户发送请求=>Controller将请求转发给Agent Service

  2. Agent Service 调用主题生成的方法，利用ChatClient 生成主题。

  3. 调用大纲规划方法，生成的主题传入，利用ChatClient生成大纲。可以调用外部工具协作

  4. 将大纲传入全文生成方法，利用ChatClient生成内容。

  5. 最后执行润色，调整整体文章的风格，输出最终文章。

  6. 主题之后的步骤都可以调用外部工具实现。所有的结果都保存到ChatMemory 中。
